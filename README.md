# Project B

# 1. О проекте

Project B - библиотека вспомогательных функций на Python для работы с датами, строками, файлами и журналированием. Она предназначена для повторного использования в других программных проектах и позволяет выносить типовые операции в отдельные модули.

## Работа с датами

Модуль date_utils.py содержит функции для выполнения операций с датами. Он используется для получения текущей даты и представления даты в нужном формате.

## Обработка строк

Модуль string_utils.py предназначен для преобразования текстовых данных. В частности, функции этого модуля могут использоваться для изменения регистра символов и обращения строки.

## Работа с файлами

Модуль file_utils.py предоставляет функции для работы с файлами. Он используется при чтении текстовых данных, сохранении содержимого и получении информации о файлах.

При обработке файлов следует учитывать существование указанного пути, права доступа и кодировку текста.

## Журналирование

Модуль logger_utils.py отвечает за журналирование событий. Регистрация сообщений помогает отслеживать выполнение операций и диагностировать ошибки при работе приложения.

# 3. Установка

Перейдите в каталог библиотеки:

```bash
cd libs/project-b
```

Если Project B клонирован как отдельный репозиторий, перейдите непосредственно в его корневой каталог.

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его в Windows CMD:

```bash
.venv\Scripts\activate.bat
```

В PowerShell:

```bash
.\.venv\Scripts\Activate.ps1
```

В Git Bash:

```bash
source .venv/Scripts/activate
```

Установите библиотеки в режиме разработки:

```bash
python -m pip install -e .
python -m pip install pytest
```

# 4. Применение

Модули доступны по именам файлов без префикса src.


# 5. Разработка и сопровождение

Разработка и сопровождение

При добавлении функциональности рекомендуется:

- Размещать новые функции в модуле, соответствующем их назначению.
- Использовать понятные имена функций и аргументов.
- Документировать назначение функций, параметры и возвращаемые значения.
- Обрабатывать ожидаемые ошибки.
- Добавлять автоматизированные тесты.
- Перед фиксацией изменений запускать весь набор тестов.
